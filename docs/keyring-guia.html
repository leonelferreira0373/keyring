Keyring

Guia de comandos. Um cofre local para Windows com gavetas numeradas (1, 2, 3…), uma por empresa ou projecto, com valores, notas e ficheiros de qualquer tipo.

Regra de ouro: tudo o que mexe em segredos começa por keyring sudo. Sem sudo só se vêem nomes e estados, nunca valores. A password do sudo é 1234 até a mudares com keyring sudo passwd. Uma gaveta pode ser dita pelo número (1) ou pelo nome (acme, sem maiúsculas nem acentos); nomes com espaços vão entre plicas: 'Acme Corp'.

1Sem password: ver o que existe

keyring ls

Lista todas as gavetas: número, nome, entidade, quantos itens e quantos a rodar.

keyring

O índice completo para uma IA: todas as gavetas, itens, estados e projectos. Nunca mostra valores.

keyring --json

O mesmo índice em JSON (para programas).

keyring ajuda-ia

O guia e as regras para uma IA.

2Entrar (sudo)

keyring sudo

Pede a password (1234 por omissão) e abre a sessão por 15 minutos, para todo o PC. Dentro dela não volta a pedir.

keyring sudo --minutos 60

Abre a sessão por 60 minutos (de 1 a 1440).

keyring sudo -k

Fecha a sessão já.

keyring sudo passwd

Muda a password (pede a antiga e a nova duas vezes).

Cinco passwords erradas seguidas bloqueiam 5 minutos. Num script: echo 1234 | keyring sudo.

3Ver uma gaveta

keyring sudo acme ls

Lista tudo o que há na gaveta em texto simples: ficha, itens, tipo, estado, variável, nota. Os valores aparecem se estiveres num terminal; senão vêm como ***(comprimento). Para os veres sempre: --mostrar.

4Imprimir uma gaveta (rec)

keyring sudo acme rec txt > C:\pasta\acme.txt
keyring sudo acme rec pdf C:\pasta\acme.pdf

A gaveta inteira, valores incluídos, em texto ou em PDF. Sem txt nem pdf, faz PDF.

keyring sudo 'acme' 'globex' rec pdf C:\pasta

Vários PDFs de uma vez: um ficheiro por gaveta, dentro da pasta (acme.pdf, globex.pdf).

Atenção: o > é do terminal. Funciona em cmd e Git Bash; no PowerShell 5.1 estraga PDFs, por isso aí escreve o caminho no fim em vez do >. Os ficheiros do rec têm os segredos em texto simples: apaga-os quando acabares.

5Criar e guardar

keyring sudo criar 'Acme Corp' --entidade AC

Cria uma gaveta (recebe o próximo número). Opções: --ficha-de ficheiro.md (o texto da ficha) e --numero N.

keyring sudo acme pôr cloudflare.token --env CLOUDFLARE_API_TOKEN --descricao "conta de teste"

Guarda um valor: pede-o sem aparecer no ecrã. Nomes de item: minúsculas, números, ponto e sublinhado. --env é o nome da variável que o correr cria.

keyring sudo acme pôr chave.pem C:\chaves\servidor --env SSH_SERVIDOR

Guarda um ficheiro de qualquer tipo (PDF, chave, imagem, .env…).

keyring sudo acme pôr como.fazer notas.md --tipo nota
printf %s 'valor' | keyring sudo acme pôr x --stdin

Uma nota (texto). Com --stdin o valor vem da entrada (a sessão sudo tem de estar aberta antes).

keyring sudo acme ficha --de ficha.md
keyring sudo acme ficha

Define e mostra a ficha da gaveta (o que é o projecto, onde corre). A ficha e as notas não são secretas.

6Mexer nos itens

ComandoO que faz
keyring sudo acme estado cloudflare.token rodarMarca o estado: ok (e a data de hoje), rodar ou revogado.
keyring sudo acme copiar cloudflare.tokenCopia o valor; a área de transferência limpa-se em 30 s e fica fora do histórico do Windows.
keyring sudo acme abrir como.fazerAbre a nota ou o ficheiro na aplicação do Windows, numa pasta temporária que se apaga sozinha.
keyring sudo acme tirar chave.pem C:\pastaExtrai um ficheiro para uma pasta.
keyring sudo acme remover cloudflare.tokenApaga o item e as suas versões antigas.

Cada item guarda a versão actual e as 5 anteriores: ao rodar um segredo, o antigo não se perde.

7Usar os segredos sem os mostrar (correr)

keyring sudo acme correr -- bash -c 'curl -s -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" https://api.cloudflare.com/client/v4/user/tokens/verify'

Corre o comando com os itens da gaveta que têm --env como variáveis de ambiente, só dentro dele. A saída vem censurada: qualquer segredo que apareça é trocado por ***. É assim que um agente de IA (como o Claude Code) usa as credenciais sem as ver. Itens revogado não se injectam.

8Projectos (itens de várias gavetas)

keyring sudo projecto criar site --descricao "Website da Acme"
keyring sudo projecto adicionar site 1/github.token 1/cloudflare.token 2/db.senha
keyring sudo projecto site
keyring sudo projecto site correr -- <comando>

Um projecto é uma lista de itens, mesmo de gavetas diferentes. correr carrega tudo o que o projecto precisa de uma vez. Também: keyring sudo correr --projecto site -- <comando>.

9Cópia de recuperação

keyring sudo acme exportar D:\copias
keyring sudo importar D:\copias\acme-20260101.keyring

Um só ficheiro com a gaveta inteira (histórico incluído), cifrado com uma frase-passe tua (mínimo 8 caracteres). Serve para recuperar se o PC avariar. Guarda-o num disco externo, nunca num servidor. Se o número já estiver ocupado: --numero N.

Para lembrar

TemaComo é
Onde ficam os dadosC:\Users\<utilizador>\.keyring\ (só tua; fora do OneDrive e de repositórios). Só neste PC.
Variáveis de ambienteKEYRING_DIR (outra pasta de dados), KEYRING_SENHA (a password do sudo), KEYRING_FRASE (a frase-passe da recuperação).
Códigos de saída0 = bem · 1 = erro explicado · 2 = erro inesperado. Com --json os erros vão em JSON para o stderr.
LimitesValores com menos de 6 caracteres não são censurados no correr. A password 1234 só trava o uso casual: a tranca a sério é a do Windows.
Agentes de IASó funcionam neste PC, com a tua conta do Windows (um agente na nuvem ou num servidor não abre as gavetas).
