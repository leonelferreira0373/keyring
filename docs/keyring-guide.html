Keyring

Command guide. A local vault for Windows with numbered drawers (1, 2, 3…), one per company or project, holding values, notes and files of any kind. The command names are Portuguese; this guide explains each one.

Golden rule: everything that touches secrets starts with keyring sudo. Without sudo you only see names and states, never values. The sudo password is 1234 until you change it with keyring sudo passwd. A drawer can be named by number (1) or by name (acme, case and accents ignored); names with spaces go in quotes: 'Acme Corp'.

1No password: see what exists

keyring ls

Lists every drawer: number, name, entity, how many items and how many are due for rotation.

keyring

The full index for an AI: every drawer, item, state and project. Never shows values.

keyring --json

The same index as JSON (for programs).

keyring ajuda-ia

The guide and rules for an AI agent ("ajuda-ia" = AI help).

2Sign in (sudo)

keyring sudo

Asks for the password (1234 by default) and opens a session for 15 minutes, for the whole PC. Inside it, no more prompts.

keyring sudo --minutos 60

Opens the session for 60 minutes (1 to 1440).

keyring sudo -k

Closes the session now.

keyring sudo passwd

Changes the password (asks for the old one and the new one twice).

Five wrong passwords in a row lock it for 5 minutes. In a script: echo 1234 | keyring sudo.

3Look inside a drawer

keyring sudo acme ls

Lists everything in the drawer as plain text: description, items, type, state, variable, note. Values are shown when you are in a terminal; otherwise they appear as ***(length). To always see them: --mostrar.

4Print a drawer (rec)

keyring sudo acme rec txt > C:\folder\acme.txt
keyring sudo acme rec pdf C:\folder\acme.pdf

The whole drawer, values included, as text or PDF. Without txt or pdf it makes a PDF.

keyring sudo 'acme' 'globex' rec pdf C:\folder

Several PDFs at once: one file per drawer, inside the folder (acme.pdf, globex.pdf).

Careful: the > belongs to the terminal. It works in cmd and Git Bash; in PowerShell 5.1 it corrupts PDFs, so there write the path at the end instead of using >. The files from rec contain secrets in plain text: delete them when you are done.

5Create and store

keyring sudo criar 'Acme Corp' --entidade AC

Creates a drawer (gets the next number). Options: --ficha-de file.md (the description text) and --numero N.

keyring sudo acme pôr cloudflare.token --env CLOUDFLARE_API_TOKEN --descricao "test account"

Stores a value: asked for without echo. Item names: lowercase, digits, dot and underscore. --env is the variable name that correr creates.

keyring sudo acme pôr key.pem C:\keys\server --env SSH_SERVER

Stores a file of any kind (PDF, key, image, .env…).

keyring sudo acme pôr how.to notes.md --tipo nota
printf %s 'value' | keyring sudo acme pôr x --stdin

A note (text). With --stdin the value comes from the input (the sudo session must be open first).

keyring sudo acme ficha --de ficha.md
keyring sudo acme ficha

Sets and shows the drawer's description (the "ficha": what the project is, where it runs). The description and notes are not secret.

6Work with items

CommandWhat it does
keyring sudo acme estado cloudflare.token rodarSets the state: ok (with today's date), rodar (rotate) or revogado (revoked).
keyring sudo acme copiar cloudflare.tokenCopies the value; the clipboard is cleared after 30 s and kept out of Windows clipboard history.
keyring sudo acme abrir how.toOpens the note or file in the Windows app, in a temp folder that deletes itself.
keyring sudo acme tirar key.pem C:\folderExtracts a file to a folder.
keyring sudo acme remover cloudflare.tokenDeletes the item and its old versions.

Each item keeps the current version and the 5 previous ones: when you rotate a secret, the old one is not lost.

7Use secrets without showing them (correr)

keyring sudo acme correr -- bash -c 'curl -s -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" https://api.cloudflare.com/client/v4/user/tokens/verify'

Runs the command with the drawer's items that have --env as environment variables, only inside it. The output is redacted: any secret that shows up is replaced by ***. This is how an AI agent (such as Claude Code) uses credentials without seeing them. Items marked revogado are never injected.

8Projects (items from several drawers)

keyring sudo projecto criar site --descricao "Acme website"
keyring sudo projecto adicionar site 1/github.token 1/cloudflare.token 2/db.senha
keyring sudo projecto site
keyring sudo projecto site correr -- <command>

A project is a list of items, even from different drawers. correr loads everything the project needs at once. Also: keyring sudo correr --projecto site -- <command>.

9Recovery backup

keyring sudo acme exportar D:\backups
keyring sudo importar D:\backups\acme-20260101.keyring

A single file with the whole drawer (history included), encrypted with a passphrase of your own (8 characters minimum). It lets you recover if the PC dies. Keep it on an external disk, never on a server. If the number is already taken: --numero N.

Worth remembering

TopicHow it works
Where the data livesC:\Users\<user>\.keyring\ (yours only; keep it out of OneDrive and repositories). This PC only.
Environment variablesKEYRING_DIR (another data folder), KEYRING_SENHA (the sudo password), KEYRING_FRASE (the backup passphrase).
Exit codes0 = ok · 1 = explained error · 2 = unexpected error. With --json errors go to stderr as JSON.
LimitsValues shorter than 6 characters are not redacted by correr. The 1234 password only stops casual use: the real lock is your Windows account.
AI agentsThey only work on this PC, under your Windows account (an agent in the cloud or on a server cannot open the drawers).
